Learning Management System (LMS)

A full stack Learning Management System with an Admin Dashboard built using modern web technologies.

Features:
User Authentication (Login/Signup)
Admin Dashboard
Course Management
About
Blogs
Create, Update, Delete Courses,Blogs
User Management


Tech Stack:
Frontend: React JS
Backend: Node.js, Express
Database: MySql

Installation
1. Clone the repository
2. Install dependencies:
   npm install
3. Run the project:
   npm start

Future Improvements:
Payment Integration
Video Lectures
Student Progress Tracking
Responsive Design

This project demonstrates full stack development skills including frontend UI, backend APIs, and database integration.
